# 🎬 Oven Trio Mobile

**All-in-One Multimedia Studio for Android**

Oven Trio Mobile is an Android multimedia application currently under active development, bringing the capabilities of Oven Trio Studio to mobile devices.

Download, trim, convert, play, record, and analyze media — all in one application.

> 🚧 **Development Status: Work in Progress**
>
> Oven Trio Mobile is currently under development. Features are being implemented and tested. No public APK release is available yet.

## 🚀 Planned Features

### 📥 Downloader
- Video and audio downloads from supported websites.
- Quality and format selection.
- Download management and progress tracking.

### ✂️ Trim
- Multi-segment video trimming.
- Timeline-based editing.
- Smart cutting and precise export.

### 🔄 Converter
- Video and audio conversion.
- Multiple media formats and codecs.
- Batch processing.

### 🎵 Media Player
- Local audio and video playback.
- Playback controls and media navigation.

### 📊 File Info
- Detailed media and stream information.
- Codec, bitrate, resolution, and metadata analysis.

### 🎙️ Recorder
- Screen and audio recording.
- Recording configuration and output management.

## 🛠️ Technology

- .NET MAUI / C#
- C++ / Android NDK
- FFmpeg
- Android Media APIs

## 📱 Platform

**Target:** Android ARM64 (`arm64-v8a`)
